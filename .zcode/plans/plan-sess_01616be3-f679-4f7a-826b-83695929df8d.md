## 目标

安装 ZCode monorepo 的依赖，并在本地把开发环境跑起来验证（Web 端 + 桌面端）。

## 步骤

### 1. 环境准备
- `source ~/.nvm/nvm.sh && nvm use 24.19.0`（每条命令带前缀，因为 shell 状态不持久）
- 用 corepack 激活 pnpm 10.33.2（读 `packageManager` 字段）：`corepack enable pnpm && corepack prepare pnpm@10.33.2 --activate`，校验版本；失败则 `npm i -g pnpm@10.33.2` 兜底
- 不装精确的 24.14.0：nvm 里没有，24.19.0 满足根 `engines >=24`，pnpm 默认不强制 engines（zcode-cli 钉 24.14.0 最多告警，不影响安装运行）

### 2. 基线检查
- `node scripts/check-workspace-freshness.mjs`（AGENTS.md 要求的开工检查，只做 git fetch + 落后检测）

### 3. 安装依赖 + 构建
- `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ pnpm bootstrap`（= 安装全部 workspace 依赖 + 准备桌面运行资源 + `build:bootstrap` 构建各包，默认跳过远程资源）。预计 5–15 分钟，Electron 41.0.3 二进制和 node-pty 原生重建走镜像
- 若 npmjs 官方源过慢/失败：用 `--registry=https://registry.npmmirror.com` 重试，不改动仓库里被跟踪的 `.npmrc`

### 4. 验证 Web 端能跑
- 后台运行 `pnpm dev:web`，轮询 http://localhost:5173（Web）和 http://localhost:3030（后端 API）确认都起来后停掉

### 5. 验证桌面端能跑
- 后台运行 `ZCODE_DATA_BASE_DIR=$HOME/.zcode-dev-home pnpm dev:desktop:test`（test 环境配置 + 隔离数据目录，避免污染你正在使用的 ZCode 正式版 `~/.zcode` 数据），会弹出一个 Electron 开发窗口，确认进程稳定运行后停掉

### 6. 汇报
- 汇报安装耗时、Web/桌面能否跑起来、遇到的问题及处理方式；顺带跑 `pnpm typecheck` 报告真实结果（不把失败写成通过）

## 风险与说明
- Electron / node-pty 原生模块在 postinstall 重建，网络慢会拖时间，已走 npmmirror 缓解
- corepack 拉取 pnpm 10.33.2 偶发签名/网络问题，有 npm 全局安装兜底
- dev 桌面实例用独立数据目录，不影响现有 ZCode 正式版；验证完会关闭进程
