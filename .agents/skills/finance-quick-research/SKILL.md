# 快捷研究（单股速览）

对指定 A 股标的做一轮快速研究，输出结构化速览卡片。全程只使用 `finance` MCP 工具，不发起子任务，目标 1 分钟内完成。

## 执行步骤

1. **解析标的**：用 `mcp__finance__search_securities` 把用户给的名称/代码解析成标准 `ts_code`。解析不到就停下向用户确认，不要猜。
2. **并行取证**（一次消息里发多个工具调用）：
   - `mcp__finance__get_daily`（120 日行情）
   - `mcp__finance__get_daily_basic`（最新估值：PE/PB/市值/换手/量比）
   - `mcp__finance__get_financials`（近 6 期营收/净利/ROE/毛利率/同比）
   - `mcp__finance__get_moneyflow`（近 10 日主力资金）
3. **输出格式**（严格遵守，用 Markdown）：

```
## {公司名}（{ts_code}）基本面速览

**关键指标**
| 指标 | 数值 | 变化/分位 |
|---|---|---|
（营收及同比 / 归母净利及同比 / 毛利率 / ROE / 资产负债率 / PE(TTM) / 总市值 / 换手率）

**技术面一句话**：近 120 日走势特征（区间、趋势方向、量能变化），只用 get_daily 的真实数据描述。

**资金面一句话**：近 10 日主力净流入合计与方向。

**一句话结论**：把上面三面各压缩成半句合成一段，注明"数据截至 {最新日期}，仅信息整理不构成投资建议"。
```

4. **引用纪律**：每个数字必须来自工具返回值，不得编造或外推；工具返回 null 的指标写"暂缺"并注明可能需要更高 Tushare 积分档。

## 边界

- 只做数据整理与客观描述，不给买卖建议、不预测价格。
- 用户追问深挖（如"利润率为什么变"）时可用 WebSearch 补充公开信息，注明来源。
- 用户要"深度研究/多空辩论/评级"时，提示改用 finance-deep-research 技能。
